# docs 索引

規則見 [`文件規範.md`](文件規範.md)：文件分四層（規則、規格、計劃、紀錄），每份只屬於一層。
**新增文件的同一個 commit 必須在這裡登記**，`bstack check` 會檢查。
衝突時的優先序：程式 > 規格 > 計劃 > 紀錄。

## 規則

- `../CLAUDE.md`：開發必守規則，只放規則與「去哪裡查」。
- `文件規範.md`：文件怎麼放、怎麼改。

## 規格（現行系統的樣子）

每個領域一份入口文件，只寫現況；細節文件放在同名資料夾。

| 蕃茄鐘 | `規格/蕃茄鐘.md` | （無） |

## 紀錄（只追加、不修改）

- `紀錄/上線紀錄.md`：每次發版與遠端設定變更，日期倒序。
- `紀錄/決策紀錄.md`：一件事一段，日期／決定／理由／影響哪份規格。

## 封存

`archive/`：已被取代或任務結束的文件，清單見 `archive/README.md`。
