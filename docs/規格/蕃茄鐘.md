# 蕃茄鐘
最後核對：2026-10-23（對應版本 ebec59e）
程式範圍：src/
相關規則：CLAUDE.md §0

## 概要

像素風格的網頁蕃茄鐘，Vite + Vue 3 + TypeScript 的單頁靜態網站，發佈在 GitHub Pages（https://billwang99.github.io/Tomato_Clock/）。沒有後端、沒有帳號，所有資料只存在使用者瀏覽器的 localStorage。

## 程式分層

| 層 | 位置 | 負責 |
|---|---|---|
| 核心（純函式） | `src/core/` | 計時狀態機、設定檢查、今日統計、點陣字與蕃茄點陣圖、文案；不碰畫面與瀏覽器 API |
| 共用邏輯 | `src/composables/` | 把核心接上 Vue：現在時間、存檔、聲音、螢幕常亮、分頁標題 |
| 通用元件 | `src/components/base/` | 像素按鈕、點陣數字、步進器、開關、面板、對話框；不知道蕃茄鐘業務 |
| 業務元件 | `src/components/business/` | 模式分頁、蕃茄主角、倒數、輪次、控制列、設定、統計、碎片、時間到橫幅 |
| 頁面 | `src/pages/TimerPage.vue` | 只排版，流程在 `usePomodoroSession` |
| 樣式 | `src/styles/tokens.css` | 顏色（Sweetie 16 色盤）、字級、間距的唯一來源 |

## 計時規則

- 三種階段：專注（預設 25 分）、短休息（5 分）、長休息（15 分）。
- 專注完成後，本輪累積到「長休息間隔」（預設 4）個就接長休息，否則接短休息；休息完回到專注。
- 離開長休息（休完、跳過、手動切走）都會開始新的一輪。
- 跳過、手動切換分頁都不算完成，不加蕃茄數。
- 計時以「結束時間戳記」計算：切到背景、鎖螢幕、重新整理後回來，剩餘時間仍然正確。
- 時間到時，下一段從「發現時間到的那一刻」起算（不從原本的結束時間起算）。
- 「自動開始下一段」關閉時，下一段停在未開始；開啟時立刻開始。
- 改設定只影響還沒開始的這一段；進行中或暫停中的不受影響，統計記實際跑的長度。

## 時間到的提示

- 畫面：上方黃色橫幅（按「知道了」或任何操作後消失）、全畫面閃三下、專注完成時蕃茄跳一下並噴出像素碎片。
- 分頁標題變成「⏰ 時間到！」。
- 聲音：Web Audio 即時合成 8-bit 音效；Android 另外震動。
- 已知限制（2026-10-23 已確認接受）：iOS 鎖螢幕或切到別的 App 時網頁被暫停，時間到那一刻不會響。回到網頁時立刻顯示橫幅，提示音在使用者下一次點畫面時補播。設定裡的「計時中螢幕常亮」可避免手機自動鎖定。

## 存在瀏覽器的資料

| key | 內容 | 壞掉時 |
|---|---|---|
| `tomato:settings` | 時長、長休息間隔、自動開始、音效、音量、螢幕常亮、掃描線 | 逐欄位檢查，不合法的用預設值 |
| `tomato:timer` | 目前階段、狀態、總長、剩餘、結束時間、本輪完成數 | 整份重來（專注 25:00） |
| `tomato:stats` | 日期、今日完成數、今日專注分鐘 | 歸零；跨日自動歸零 |

## 版面

| 寬度 | 對應裝置 | 版面 |
|---|---|---|
| < 360 | 摺疊機外螢幕 | 單欄，隱藏標題、分頁字縮小 |
| 360～599 | iPhone 13 mini（375）到 6.7 吋（430） | 單欄；主要按鈕在下方；設定是底部面板 |
| ≥ 600 | 摺疊機展開、平板、電腦 | 左計時、右設定兩欄，中間留寬縫避開摺痕 |
| ≥ 600 且高度 ≤ 520 | 手機橫放 | 蕃茄在數字左邊，設定欄自己捲動，不用捲就按得到主要按鈕 |

所有畫面都用 safe-area 留白避開瀏海與底部橫條，高度用 `dvh`；「減少動態效果」開啟時關閉所有動畫。

## 字型與圖示

- 中文像素字型：Fusion Pixel Font 12px（SIL OFL 1.1，授權檔 `src/assets/fonts/OFL-fusion-pixel.txt`），只保留介面用到的字。
- **改了介面文字（新增中文字）後要重跑** `node scripts/subset-font.mjs <完整字型.woff2>`，否則新字會用系統字型顯示。
- 計時數字是自己畫的 5×7 點陣字（`src/core/pixelFont.ts`），不靠字型。
- 圖示由 `npm run icons` 從同一份蕃茄點陣圖產生到 `public/icons/`。

## 發佈

推上 `main` 後 GitHub Actions（`.github/workflows/deploy.yml`）依序執行 lint、測試、建置，通過才發佈到 GitHub Pages。repo 的 Settings → Pages → Source 必須設成「GitHub Actions」。
